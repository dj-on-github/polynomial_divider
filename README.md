# polynomial_divider
A simple python program to divide polynomials

Polynomial Division Examples:
============================================================

Test 1:
(x^2 - 1) / (x - 1)
Quotient:  x + 1.0
Remainder: 0

Test 2:
(x^3 + 2x^2 + 3x + 4) / (x + 1)
Quotient:  x^2 + x + 2.0
Remainder: 2.0

Test 3:
(2x^2 + 3x + 1) / (x + 1)
Quotient:  2x + 1.0
Remainder: 0

Test 4:
(x^2 + 1) / (x^2 + 1)
Quotient:  1.0
Remainder: 0

Test 5:
(x^3 + 1) / (x^2 + x + 1)
Quotient:  x - 1.0
Remainder: 2.0

Test 6:
(5x^4 - 3x^2 + 7) / (x - 2)
Quotient:  5x^3 + 10x^2 + 17x + 34.0
Remainder: 75.0


See the code for examples of how to call the routines form python.
